DAYLOCK - daytime Midtown + Hideout for Deadlock
================================================

Turns the night maps into a sunny afternoon: a ray-traced sun with real shadows, blue sky with
clouds, daylight bounce in streets and interiors, toned-down night lamps and window glow, and
reflections, glows and colour tuned for daylight. Covers Midtown (all matches) and the Hideout.

Purely visual and client-side. Gameplay geometry, fog/steam cover, items and spawns are untouched.
Runs about 7% faster than stock (467 vs 438 FPS average at 11 static spots around Midtown),
because the night storm/smog atmosphere is gone; gameplay fog and steam cover are unchanged.

INSTALL
-------
Deadlock Mod Manager: use the install page {PAGE}
(custom mod sources need the Nightly build of the Mod Manager for now).

Manual: put pak99_dir.vpk into
    <Steam>\steamapps\common\Deadlock\game\citadel\addons\
(if pak99_dir.vpk already exists there, rename this one to any free pakNN_dir.vpk number).
The addons folder must be enabled in game\citadel\gameinfo.gi (any mod manager does this).

UNINSTALL
---------
Disable/remove it in the mod manager, or delete the .vpk.

AFTER A DEADLOCK UPDATE
-----------------------
This mod contains full copies of the Midtown and Hideout maps. If Valve changes one of those
maps, disable Daylock until an updated version is posted (an outdated map copy can look wrong
or fail to load). Updates that don't touch the maps don't affect it.
